# Machine Learning & AI Portfolio

Welcome to my Machine Learning and Artificial Intelligence portfolio. This repository contains my implementations of generative AI architectures built from scratch, as well as predictive analytics pipelines for structured datasets.

## 📂 Projects Overview

### 1. [Generative AI: Denoising Diffusion Model (DDPM/DDIM)](./Generative_AI_Diffusion_Model)
* **Description:** A probabilistic generative diffusion model built from scratch to explore image synthesis. Includes a custom PyTorch U-Net backbone, multi-head self-attention, and a custom Markov chain training loop minimizing the ELBO loss.
* **Tech Stack:** PyTorch, NumPy, OpenCV, Python.

### 2. [Advanced House Prices Regression (Kaggle)](./Kaggle_House_Prices)
* **Description:** An end-to-end predictive pipeline that predicts housing prices. Features advanced EDA, log-scaling for skewed distributions, and an ensemble model.
* **Tech Stack:** Scikit-Learn, XGBoost, LightGBM, Pandas, Seaborn.
* **Result:** Achieved an RMSLE of 0.12651.

### 3. [Titanic Survival Classification (Kaggle)](./Kaggle_Titanic)
* **Description:** A binary classification pipeline focusing on robust feature engineering (Title/Family Size extraction), missing value imputation, and categorical encoding.
* **Tech Stack:** Scikit-Learn, Random Forest, Pandas.
* **Result:** Achieved 78.7% classification accuracy.
